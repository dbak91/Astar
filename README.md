# A Star Cleaning Specialists

Static one-page website (plain HTML/CSS, no build step) for an exterior cleaning business covering Manchester and surrounding areas. The site uses real project photography, accessible semantic HTML and a responsive editorial layout.

## Publishing
In the repo go to Settings → Pages → Source: "GitHub Actions". Pushing to `main` deploys the site via `.github/workflows/pages.yml` (no build step needed; all paths are relative so it works under `/Astar/`).

## Before going live

- Replace the placeholder phone number and email address in `index.html`.
- Confirm the wording of insurance and service-area claims.
